How to install Forge TV

  1. Download the APK

    Use the download above on your TV, phone or computer. This site links to the latest published Forge TV release.

  2. Transfer it to your TV, if needed

    Use your TV's browser or downloader, a USB drive, or the Android Debug Bridge (ADB) from a computer.

  3. Allow installation from that source

    Android may prompt you to allow your chosen file manager or installer to install apps from outside its app store. Only enable this for sources you trust.

  4. Open Forge TV and add your playlist

    Use an M3U URL, M3U file or Xtream Codes credentials from your own legitimate provider. Forge TV does not supply content.

Device compatibility: Forge TV is built for Android TV and Google TV and supports Android 6.0 or later. It also has interfaces for Android phones, tablets and supported Android-based VR headsets. Your device may differ in how it installs APK files.

Updates and release information

Forge TV checks for new releases after launch, with options to update now, later or skip a version. You can adjust this in Settings → About. For release files and version history, visit the GitHub releases page.

After installation

Start with the playlist setup guide, then explore the remote-control guide to get comfortable with channels, the programme guide and playback shortcuts.

Forge TV is a player only. No channels or subscriptions are supplied. Use your own lawful content sources.
